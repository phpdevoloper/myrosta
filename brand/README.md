# Brand source files

Design files kept for reference and for making print or office material. **None of these are served by the site.** The icons the app and the landing page use live in `img/`.

| File | What it is |
|---|---|
| `myrosta-logo.svg` | The full logo |
| `myrosta-mark.svg` | The mark on its own (the AM / PM / CST bars) |
| `Myrosta - Staff Quick Start.svg` | The one-page staff quick-start sheet |
| `qr-myrosta.png` | QR code to myrosta.com.au, for posters and handouts |

# Myrosta — trade mark application notes (IP Australia TM Headstart)

**Mark:** `MYROSTA` — apply as a **plain word mark** (broadest protection; covers any styling/logo). A stylised logo can be filed separately later.
**Owner:** Dr Ranjith Kandavelu (or a company, if/when you set one up — decide before filing, as the owner is hard to change later).
**Route:** TM Headstart (pre‑assessment) → convert to full application. Each class is a **separate fee**.
**Classes:** 9 (downloadable software / apps) + 42 (SaaS / hosted software).

## Class 9 — downloadable software & mobile apps

**Recommended (complete):**

> Computer application software; downloadable mobile applications for employee scheduling and rostering.

## Notes / decisions
- **Keep the wording general (workforce/staff scheduling), not "medical."** Tying it to healthcare would *narrow* your protection and might pull in class 44 unnecessarily. The software's function is rostering/scheduling — describe it that way.
- **Word mark first.** Register `MYROSTA` as plain text for the widest cover; do the logo later if wanted.
- **The one thing to watch — ROSTRA.** IP Australia's register shows **ROSTRA** registered in **class 9** (automotive cruise‑control electronics, reg. 730142) and **ROSTrac** in classes 9/35/42. The Headstart pre‑assessment exists precisely to tell you whether the examiner would cite either against MYROSTA. Their goods (car electronics) differ from roster software, so there's a real argument they're not "similar goods" — but that judgement is the whole point of Headstart.
- **Why we did NOT go with "Mustero":** the IP search found **MUSTER** registered as a bare word in **classes 9 and 35**, plus a cluster of software "Muster" marks (Data Muster, Startup Muster, OpsMuster, Mustered) in 9/42. "Mustero" = "Muster" + o → high deceptive‑similarity risk in your own classes. Myrosta's position (vs ROSTRA, different word, different goods) is stronger.
